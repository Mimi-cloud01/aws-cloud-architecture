# AWS Cloud Infrastructure & Media Streaming Architecture

## Overview
This repository contains cloud architecture designs, deployment steps, and cost optimizations for AWS infrastructure.

## Key Features & Highlights
* **StreamWave Media Streaming Architecture**: Implemented AWS CloudFront edge routing across regional locations to optimize video playback and reduce latency.
* **Cost Optimization**: Utilized S3 Origin Access Control (OAC) and S3 Intelligent-Tiering to minimize storage and egress costs.
* **VPC Network Deployment**: Hands-on deployment of ShopEase-VPC (`10.10.0.0/16`) including public/private subnets, Internet Gateways, Security Groups, and Apache web server setup on Amazon Linux 2023.
* **LMS Infrastructure Cost Analysis**: Comprehensive Cape Town regional pricing calculations covering EC2, S3, EBS, and CloudFront services.
